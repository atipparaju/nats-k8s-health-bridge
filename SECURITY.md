# Security Policy

## Supported Versions

**No released version is currently supported.** GitHub had no Releases or Git tag refs when checked on 2026-11-04. The historical `0.1.0` milestone and chart packaging version do not establish a published security-supported release.

| Version | Status | Security support |
| --- | --- | --- |
| `main` | Development source preview | Best effort, not a published supported version |
| Internal `0.1.0` baseline | Historical milestone, not a release | Not supported |
| Future versions | Not published or approved | Policy to be established before release |

## Reporting a Vulnerability

**Do not report security vulnerabilities in public GitHub issues.** Use [GitHub Security Advisories](https://github.com/atipparaju/nats-k8s-health-bridge/security/advisories/new) for private coordinated reporting where access permits. Before public visibility is enabled, external reporters may not have access to the repository. After publication, verify that private vulnerability reporting is available. Include a description, reproduction steps, impact and suggested mitigation. No fixed acknowledgement, fix or disclosure deadline is committed while the project is unreleased.

## Scope

This policy covers the bridge binary, container build and Helm chart, not NATS server itself. Report NATS vulnerabilities to the [NATS project](https://github.com/nats-io/nats-server/security).

## Credits

With permission, responsible researchers may be acknowledged in future release notes.
